# Canada Explorer Prototype v39 — Saskatchewan Full Frame

Open `index.html` in a web browser. For best local-browser compatibility with media and speech features, use the included local server if needed.

This version includes the complete Canada lesson, the full B.C. lesson, and full 8-minute lessons for Alberta, Saskatchewan, Manitoba, Ontario, Quebec, New Brunswick, Nova Scotia, Prince Edward Island, Newfoundland and Labrador, Yukon, Northwest Territories, and Nunavut.


## Navigation wiring
The Home-page How to Use This App and Fun Facts controls use dedicated handlers (`showHelp()` and `showFunFacts()`) and must not call `startCanada()`.
